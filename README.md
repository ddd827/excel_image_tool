Excel 图片批量插入工具
一个用 Python 写的小工具：选择本地图片，批量插入到 Excel 表格中，并按行或按列自动排列、填满单元格。

功能
弹窗多选图片（可按住 Ctrl 多选，或 Ctrl+A 全选）

弹窗选择 Excel 文件，支持 .xlsx、.xls、.xlsm

支持按行排列或按列排列

支持指定起始单元格（比如 B2，字母大小写不限）

支持设置图片之间的间距

图片自动填满对应单元格

输入 q / exit / 退出，或按 Ctrl+C，可随时退出

支持任意盘符、任意文件夹里的图片和 Excel

环境要求
Python 3.8 以上

Microsoft Excel（不是 WPS）

Windows 系统

安装依赖
在项目文件夹里打开命令行，运行：

pip install -r requirements.txt

使用方法
运行脚本：

python test.py

在弹出的窗口里选择图片（可多选）。

在弹出的窗口里选择 Excel 文件。

按提示输入：

请输入 行 或 列（输入 q 退出）：
请输入起始单元格（比如 B2，输入 q 退出）：
请输入图片间距（0 表示紧挨着，输入 q 退出）：

输入示例
输入	效果
行，B2，0	图片从 B2 开始，竖着往下排：B2、B3、B4……
行，B2，1	图片从 B2 开始，隔一行排：B2、B4、B6……
列，C1，0	图片从 C1 开始，横着往右排：C1、D1、E1……
列，C1，2	图片从 C1 开始，隔两列排：C1、F1、K1……
注意事项
运行前请关闭目标 Excel 文件，不要让它在 Excel 里打开。

图片格式支持：.jpg、.jpeg、.png、.bmp、.gif。

插入的图片会填满对应单元格，比例不同的图片可能被拉伸变形。
