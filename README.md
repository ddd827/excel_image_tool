\# Excel 图片批量插入工具



一个用 Python 写的 Windows 桌面小工具：选择本地图片，批量插入到 Excel 表格中，并按行或按列自动排列、填满单元格。



\## 功能



\- 图形界面，双击即可运行

\- 弹窗多选图片（可按住 Ctrl 多选，或 Ctrl+A 全选）

\- 弹窗选择 Excel 文件，支持 `.xlsx`、`.xls`、`.xlsm`

\- 支持按行排列或按列排列

\- 支持指定起始单元格（比如 `A1`，字母大小写不限）

\- 支持设置图片之间的间距

\- 图片自动填满对应单元格

\- 进度条显示插入进度

\- 可随时点“取消”停止插入

\- 支持任意盘符、任意文件夹里的图片和 Excel

\## 使用方法



1\. 双击 `ExcelImageTool.exe`。

2\. 点击“选择图片”，选择你要插入的图片（可多选）。

3\. 点击“选择 Excel”，选择目标 Excel 文件。

4\. 选择排列方向：行或列。

5\. 输入起始单元格，例如 `A1`。

6\. 输入图片间距，`0` 表示紧挨着，`1` 表示隔一行/一列。

7\. 点击“开始插入”。

8\. 等待进度条走完，完成后会弹窗提示。



\### 输入示例



| 方向 | 起始单元格 | 间距 | 效果 |

|---|---|---|---|

| 行 | A1 | 0 | 图片从 A1 开始，竖着往下排：A1、A2、A3…… |

| 行 | A1 | 1 | 图片从 A1 开始，隔一行排：A1、A3、A5…… |

| 列 | A1 | 0 | 图片从 A1 开始，横着往右排：A1、B1、C1…… |

| 列 | A1 | 2 | 图片从 A1 开始，隔两列排：A1、D1、G1…… |



\## 注意事项



\- 运行前请关闭目标 Excel 文件，不要让它在 Excel 里打开。

\- 图片格式支持：`.jpg`、`.jpeg`、`.png`、`.bmp`、`.gif`。

\- 插入的图片会填满对应单元格，比例不同的图片可能被拉伸变形。
